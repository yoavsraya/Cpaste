Four ways the Cpaste panel can open on Cmd+1

Each option below is a working mock with the same ten clips. Type in the search field, click a category, move with the arrow keys, and press Return to paste into the note behind the panel. The clips are examples built from your screenshot, with one image and one terminal command added.

My pick is B, with A one setting away

Most of what you copy is short text, like the hotel names in your screenshot. Rows show more of those per screen than cards do, and the preview shows the whole clip before you paste it. Search is the first thing under your fingers.

The shelf is the better view when you are hunting for a screenshot. All four options draw the same list of clips, so the app can ship B as the default and A as a second view behind a setting for little extra work. C and D do not earn a place in the first version.

What stays the same in every option

  • ⌘1 opens the panel over whatever app you are in, and the shortcut can be changed in settings.
  • Return pastes the selected clip into the app you came from. ⌘1 to ⌘9 paste by position while the panel is open.
  • Typing filters the clips straight away. Categories narrow the list further.
  • ⌘S saves the selected clip to a category. Saved clips never expire. Unsaved history is trimmed by age.
  • Images are stored at full size and shown as thumbnails.
  • Copies from password managers are skipped.
