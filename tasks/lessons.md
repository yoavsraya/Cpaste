# Lessons

## 2026-11-15 A new action needs a menu item, not only a key

- **What I did.** Added Compare (and Preview) on the Space key only.
- **What was wrong.** The user selected two clips, right-clicked, and found no Compare. A key nobody was told about is invisible.
- **Rule.** Every action on a clip goes in the right-click menu as well as on its key, in the same commit.
